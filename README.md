# Culture Vogue – Fashion Advertising System

##  Overview
Culture Vogue is a digital advertising platform designed specifically for the fashion industry.  
It enables brands, agencies, and influencers to manage campaigns, collaborate, and analyze performance through a centralized system.

##  Project Objectives
- Streamline fashion advertising workflows
- Enable influencer collaboration
- Provide real-time analytics and reporting
- Ensure secure and scalable system architecture

##  Key Features
- Campaign creation and management
- Influencer onboarding and tracking
- Analytics dashboards
- Secure authentication (OAuth2 + JWT)
- RESTful APIs for system integration

##  System Architecture
- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **Security:** HTTPS, JWT, AES-256 encryption
- **Deployment:** Docker, Kubernetes, AWS
